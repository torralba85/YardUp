- GitHub Actions CI workflow that runs lint, unit tests, typecheck, build, and Playwright e2e on every push and PR.

## Known Limitations

- Outputs are deterministic investor-demo estimates only. No live GIS, permitting, ARKit, ARCore, Mapbox, Gemini, auth, backend, or database integration is present.
- The 3D scene uses `@react-three/fiber`. On devices without WebGL the canvas falls back to the loading placeholder block (`bg-[#16251f]`), so the primary section is never blank but does not show massing geometry.
- Saved concepts are local to the browser's `localStorage`. They do not sync between devices and will be lost if the user clears site data.
- Share Link copies the current scenario URL. When `navigator.clipboard` is unavailable the URL is shown in the button text as a fallback.

## Audit Decision

`npm audit --audit-level=moderate` reports:

```
postcss <8.5.10 (moderate) — XSS via Unescaped </style> in CSS Stringify Output
  Nested under next 9.3.4-canary.0 - 16.3.0-canary.5
```

`npm audit fix --force` would downgrade Next.js to `9.3.3`, which is a breaking change incompatible with this codebase. We are **not** applying the forced fix. The advisory is acknowledged in `docs/deployment.md`. Track upstream Next.js releases and reapply when a non-breaking fix is published.

## Rollback Plan

- **Vercel:** open the deployments list, find the previous successful production deployment, and click **Promote to Production**. No data migration is required because the app is local-first.
- **Self-hosted:** redeploy the previous tag or the prior successful Docker image. There are no schema or storage migrations involved.
