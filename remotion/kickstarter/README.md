# kickstarter

## Overview
Programmatic video rendering composition and visual scenes for kickstarter.

## Interface
- `constants.ts:FPS` - Exported constant / variable
- `constants.ts:WIDTH` - Exported constant / variable
- `constants.ts:HEIGHT` - Exported constant / variable
- `constants.ts:PALETTE` - Exported constant / variable
- `constants.ts:fonts` - Re-exported symbol
- `constants.ts:SCENE_DURATIONS` - Exported constant / variable
- `constants.ts:TOTAL_DURATION_IN_FRAMES` - Exported constant / variable
- `constants.ts:CaptionSegment` - TypeScript Interface
- `constants.ts:CAPTIONS` - Exported constant / variable
- `KickstarterCampaign.tsx:KickstarterCampaign` - Exported constant / variable

### Subdirectories
- [components](<./components/README.md>) - Programmatic video rendering composition and visual scenes for kickstarter/components.
- [scenes](<./scenes/README.md>) - Programmatic video rendering composition and visual scenes for kickstarter/scenes.
